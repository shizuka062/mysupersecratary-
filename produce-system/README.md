# 🥬 Midori No Mart 青果 在庫・販売分析システム

フィリピン・アラバンの日本食品スーパー「Midori No Mart」向け、青果（野菜・果物）の
在庫・販売分析システムです。Googleスプレッドシート＋Google Apps Script で動きます。
**サーバー不要・月額費用ゼロ**で運用できます。

---

## 📁 ファイル構成

```
midori-produce-system/
├── README.md                    ← このファイル（セットアップ手順）
├── src/                         ← Apps Script に貼り付けるコード
│   ├── Code.gs                  ← メイン（セットアップ・自動計算）
│   ├── WebApp.gs                ← スタッフ用Webアプリの処理

    ├── 運用マニュアル.md          ← 管理者（あなた）向け
    ├── Staff_Guide_EN.md        ← スタッフ向け（英語）
    └── シート設計.md             ← データ設計の詳細
```

## 🚀 セットアップ手順（コピペでOK・所要15分）

### 言語について
- **スタッフのスマホ画面 → 英語**（Cucumber, Potato …）
- **あなたが見る分析シート → 日本語**
- 1つのデータを、スタッフは英語・あなたは日本語で見られます。

### STEP 1. スプレッドシートを作る
1. ブラウザで https://sheets.google.com を開く
2. 「空白のスプレッドシート」を新規作成
3. 左上のファイル名を **「Midori 青果システム」** に変更

### STEP 2. Apps Script を開く
1. 上部メニュー **「拡張機能」→「Apps Script」** をクリック
2. 新しいタブでスクリプトエディタが開きます

### STEP 3. コードを貼り付ける（3ファイル）

**① Code.gs**
1. 最初からある `Code.gs` の中身を全部消す
2. このリポジトリの `src/Code.gs` の中身を全部コピーして貼り付け

**② WebApp.gs を追加**
1. 左の「ファイル」の **＋ → スクリプト** をクリック
2. 名前を `WebApp` にする（.gs は自動でつきます）
3. `src/WebApp.gs` の中身を貼り付け

**③ StaffInput.html を追加**
1. 左の「ファイル」の **＋ → HTML** をクリック
2. 名前を `StaffInput` にする（.html は自動）
3. 中身を全部消して `src/StaffInput.html` を貼り付け

4. 上部の **💾 保存**（フロッピーアイコン）を押す

### STEP 4. 初回セットアップを実行
1. スクリプトエディタ上部の関数選択で **`setup`** を選ぶ
2. **▶ 実行** を押す
3. 初回は「承認が必要」と出る → **権限を承認**
   （自分のGoogleアカウントを選び「詳細」→「安全でないページに移動」→「許可」）
4. 完了すると、スプレッドシートに7つのシートと初期データが自動で入ります

> ✅ これで商品20件・初回入荷・為替・自動計算がすべて準備完了です。

### STEP 5. 為替レートを確認
1. スプレッドシートの **「設定」シート** を開く
2. 「採用レート PHP→JPY」に数値が入っているか確認
   - 自動（Google）が取れていればそのまま
   - 取れていなければ B2 を「手動」にして B4 に今日のレートを入力

### STEP 6. スタッフ用Webアプリを公開
1. スクリプトエディタ右上 **「デプロイ」→「新しいデプロイ」**
2. 歯車⚙「種類の選択」→ **「ウェブアプリ」**
3. 設定：
   - 説明：`スタッフ在庫入力`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **「デプロイ」** → 表示された **ウェブアプリURL** をコピー
5. そのURLをスタッフのスマホに送る（LINEやメッセージで）
   → スタッフはそのURLをホーム画面に追加すればアプリのように使えます

## 🔁 毎日の流れ

| 誰が | いつ | 何を |
|---|---|---|
| スタッフ | 毎日 営業後 | スマホで各商品の「現在在庫数」を入力して保存 |
| システム | 自動 | 販売数・回転率・発注判断を自動計算 |
| あなた | 好きな時 | 「発注判断」「ダッシュボード」を見て入荷依頼を判断 |

> 自動計算は「日次在庫」入力時と毎朝6時に自動で走ります。
> 手動で更新したい時は、メニュー **「🥬 青果システム → 全データ再計算」** を押してください。

## ❓ よくある質問

**Q. 追加で入荷したら？**
→ 「入荷管理」シートに行を足して、入荷日・商品名・入荷数・原価を入力するだけ。累計入荷数に自動反映されます。

**Q. 新しい商品を増やしたい**
→ 「商品マスター」に行を追加（商品名・英語名・単位・原価・販売価格PHP・アラート基準）。
　 計算式（実質原価/売価JPY/粗利/粗利率）は既存行をコピーして貼り付け。

**Q. 為替が変な値になった**
→ 「設定」でモードを「手動」にし、今日のGoogleレートを手入力してください。

詳しくは `docs/運用マニュアル.md` を参照してください。
