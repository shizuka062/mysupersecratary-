## ⭐ THE MOST IMPORTANT RULE / PINAKAMAHALAGANG TUNTUNIN

**"Stock" = how many are LEFT on the shelf now. NOT how many were sold.**
**"Stock" = ILAN ang NATITIRA sa shelf ngayon. HINDI kung ilan ang nabenta.**

- ✅ 12 left on the shelf → type **12**
  12 ang natitira → ilagay **12**
- ❌ 5 were sold → do NOT type 5
  5 ang nabenta → HUWAG ilagay ang 5

The app counts sales by itself. You only count what is LEFT.
Ang app na ang magku-kuwenta ng benta. Bilangin mo lang ang NATITIRA.

---

## 📋 WHAT TO DO EVERY DAY / GAWIN ARAW-ARAW

1. After closing, open the app.
   Pagkatapos magsara, buksan ang app.
2. Type the **Date** (today) and **your name**.
   Ilagay ang **Petsa** (ngayon) at **pangalan mo**.
3. Count **EVERY product** and type how many are LEFT in the green **Stock** box.
   Bilangin ang **LAHAT ng produkto** at ilagay sa berdeng **Stock** box kung ilan ang natitira.
4. Tap **"Save today's stock"**.
   I-tap ang **"Save today's stock"**.
5. A check screen appears. Read it, then tap **"✓ Yes, save"**.
   May lalabas na check screen. Basahin, tapos i-tap ang **"✓ Yes, save"**.

> If it says "X of 22 items", make sure you entered ALL items.
> Kung "X of 22 items" ang sabi, siguraduhin na LAHAT ay nailagay.

## 🎨 THE COLORED BOXES / MGA KULAY NA BOX

- 🟢 **Stock** = how many are LEFT / ilan ang NATITIRA
- 🔴 **Waste** = how many you THREW AWAY (rotten/damaged) / ilan ang ITINAPON (bulok/sira)
- 🔵 **Tasting** = how many used for tasting / ilan ang ginamit sa patikim
- 🟠 **Baked** = (Sweet Potato only) how many you baked / (kamote lang) ilan ang inihaw

> Waste / Tasting / Baked: only when it happens. If none, leave it BLANK.
> Waste / Tasting / Baked: kapag may nangyari lang. Kung wala, iwan na BLANGKO.

## ⭐⭐ WHY enter ALL items EVERY day? / BAKIT lahat, araw-araw?

This is the most important part. Please understand WHY:
Ito ang pinakamahalaga. Pakiintindi kung BAKIT:

1. **To find spoiled / rotten produce early** and remove it → less loss.
   **Para makita agad ang bulok na gulay/prutas** at maalis → mas kaunting lugi.
2. **To know what sells fast** → we reorder before it runs out → shelves are never empty.
   **Para malaman kung alin ang mabilis maubos** → makakapag-order agad → hindi mauubusan.
3. **To know what is NOT selling** → we order less → less waste.
   **Para malaman kung alin ang hindi mabili** → babawasan ang order → iwas sayang.
4. **The owner in Japan uses these numbers** to decide what to buy.
   **Ginagamit ng owner sa Japan ang mga numero** para magdesisyon kung ano bibilhin.

> If you only enter a few items, we cannot see spoilage or sales correctly.
> So please count EVERY item, EVERY day. 🙏
> Kung kakaunti lang ang ilalagay, hindi namin makikita nang tama ang sira o benta.
> Kaya pakibilang LAHAT, ARAW-ARAW. 🙏

## 🍠 SWEET POTATO (Small / Large) / KAMOTE (Small / Large)

We now sell sweet potato by size: **Small (S)** and **Large (L)**.
Nagbebenta na tayo ng kamote ayon sa size: **Small (S)** at **Large (L)**.

- Count each size separately (Raw S, Raw L, Baked S, Baked L).
  Bilangin nang hiwalay ang bawat size (Raw S, Raw L, Baked S, Baked L).
- When you bake: on **Sweet Potato (Raw)**, type how many you baked in the orange **Baked** box. Then on **Sweet Potato (Baked)**, type the baked stock left.
  Kapag nag-ihaw: sa **Sweet Potato (Raw)**, ilagay sa orange **Baked** box kung ilan ang inihaw. Tapos sa **Sweet Potato (Baked)**, ilagay ang natitirang inihaw.

> NOTE: The 1 raw sweet potato sold BEFORE we split into sizes is ALREADY handled by the manager. You do NOT need to enter it.
> PAALALA: Yung 1 hilaw na kamote na nabenta BAGO namin hatiin sa size ay INAYOS NA ng manager. HINDI mo na kailangan ilagay.
