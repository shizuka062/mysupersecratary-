# 運用マニュアル（管理者・あなた向け）

このシステムで「いつ・何を見て・どう判断するか」をまとめます。

---

## 1. 各シートの役割

| シート | 役割 | あなたの操作 |
|---|---|---|
| 商品マスター | 商品の基本情報・原価・粗利 | 初回設定／新商品追加のみ |
| 入荷管理 | 入荷履歴（初回＋追加） | 入荷したら1行追加 |
| 日次在庫 | 毎日の在庫数（スタッフ入力） | 見るだけ（基本さわらない） |
| 分析 | 全自動計算 | 見るだけ |
| 発注判断 | 発注すべき商品を色分け表示 | **毎日チェック** |
| ダッシュボード | ランキング・在庫金額・粗利 | 週次でチェック |
| 設定 | 為替・アラート閾値 | レート切替・閾値調整 |

---

## 2. 自動計算される指標の意味

| 指標 | 計算式 | 見方 |
|---|---|---|
| 累計入荷数 | 入荷管理の合計 | これまで仕入れた総数 |
| 現在在庫 | 日次在庫の最新値 | 今ある数 |
| 累計販売数 | 累計入荷数 − 現在在庫 | これまで売れた数 |
| 当日販売数 | 前日在庫＋当日入荷 − 当日在庫 | その日売れた数 |
| 販売率 | 累計販売数 ÷ 累計入荷数 | 高い＝売れている |
| 残在庫率 | 現在在庫 ÷ 累計入荷数 | 高い＝売れ残り |
| 入荷からの日数 | 今日 − 初回入荷日 | 経過日数 |
| 1日平均販売数 | 累計販売数 ÷ 入荷からの日数 | 売れるペース |
| 在庫日数 | 現在在庫 ÷ 1日平均販売数 | **あと何日でなくなるか** |
| 完売予測日 | 今日 ＋ 在庫日数 | いつ売り切れるか |
| 在庫金額JPY | 現在在庫 × 実質原価 | 在庫に眠る資金 |
| 想定売上JPY | 現在在庫 × 売価JPY | 売れたらいくらになるか |
| 想定粗利JPY | 現在在庫 × 粗利JPY | 売れたら儲けはいくらか |

---

## 3. 発注判断の見方（毎日ここを見る）

「発注判断」シートには、発注が必要な商品だけが緊急度順に表示されます。

| 表示 | 意味 | アクション |
|---|---|---|
| 🆘完売 | 在庫0 | すぐ入荷依頼 |
| 🔴至急 | 在庫日数3日以内、またはアラート基準以下 | 今すぐ入荷依頼 |
| 🟡準備 | 在庫日数7日以内 | 入荷の準備・連絡 |
| （表示なし） | 🟢十分 | 何もしなくてOK |

> 閾値（3日・7日）は「設定」シートの B6・B7 で変更できます。

---

## 4. 為替レートの運用

- **設定シート B2** で「自動」「手動」を切り替え
- **自動**：`GOOGLEFINANCE("CURRENCY:PHPJPY")` でGoogleレートを自動取得
- **手動**：B4 に今日のレートを手入力（自動が取れない・固定したい時）
- 採用レート（B5）が、商品マスターの「売価JPY換算」「粗利」に反映されます

> ⚠️ 為替が変わると粗利・在庫金額も変わります。週1回はレートを確認してください。

---

## 5. 入荷したときの操作

「入荷管理」シートに1行追加するだけ：

| 列 | 入力例 |
|---|---|
| 入荷ID | R021（任意の連番） |
| 入荷日 | 2026/06/30 |
| 商品名 | きゅうり（プルダウンから選択） |
| 入荷数 | 20 |
| 仕入原価JPY | 134 |
| 備考 | 追加入荷 |

→ 累計入荷数・販売率・在庫日数が自動で再計算されます。

---

## 6. 新商品を追加するとき

1. 「商品マスター」の最終行の下に追加
2. 入力：商品ID・商品名・英語名・単位・初期入荷数・仕入原価JPY・加工費JPY・販売価格PHP・アラート基準在庫数
3. 計算式の列（実質原価/売価JPY換算/粗利/粗利率）は、上の行をコピーして貼り付け
4. 「入荷管理」にも初回入荷を1行追加
5. メニュー「🥬 青果システム → 全データ再計算」

---

## 7. 紅はるか（焼き芋）の加工費について

- 焼き芋は「仕入原価385JPY ＋ 加工費」です
- 「商品マスター」の **加工費JPY 列**（G列）に加工費を入力してください
- 実質原価＝仕入原価＋加工費 が自動計算され、粗利に反映されます
- （未入力の場合は加工費0として計算されます）

---

## 8. トラブル時

| 症状 | 対処 |
|---|---|
| 数字が更新されない | メニュー「全データ再計算」を押す |
| 為替が空欄/エラー | 設定を「手動」にしてレート手入力 |
| スタッフがアプリを開けない | デプロイのアクセス権が「全員」か確認 |
| 計算がおかしい | 日次在庫の日付・数値が正しいか確認 |
