# シート設計（データ設計）

7枚のシートで構成。日本語の「商品名」を全シート共通の内部キーにしています。

---

## ① 商品マスター（管理者が設定）

| 列 | 項目 | 種類 | 説明 |
|---|---|---|---|
| A | 商品ID | 入力 | P01〜（任意の連番） |
| B | 商品名 | 入力 | **内部キー**（日本語） |
| C | 英語名 | 入力 | スタッフ画面の表示名 |
| D | 単位 | 入力 | 本/個/束/パック |
| E | 初期入荷数 | 入力 | 参考値 |
| F | 仕入原価JPY | 入力 | 1個あたり仕入（円） |
| G | 加工費JPY | 入力 | 焼き芋など。なければ0 |
| H | 実質原価JPY | **式** | =F+G |
| I | 販売価格PHP | 入力 | 店頭価格（ペソ） |
| J | 売価JPY換算 | **式** | =I × 採用レート |
| K | 粗利JPY | **式** | =J − H |
| L | 粗利率 | **式** | =K ÷ J |
| M | アラート基準在庫数 | 入力 | これ以下で🔴 |

---

## ② 入荷管理（入荷のたびに追加）

| 列 | 項目 | 説明 |
|---|---|---|
| A | 入荷ID | R001〜 |
| B | 入荷日 | 日付 |
| C | 商品名 | プルダウン（マスターから） |
| D | 入荷数 | その回の入荷数 |
| E | 仕入原価JPY | その回の原価 |
| F | 備考 | 初回入荷／追加入荷 など |

> 累計入荷数＝この表の商品ごとの合計。初回入荷はセットアップ時に自動登録。

---

## ③ 日次在庫（スタッフが入力）

| 列 | 項目 | 説明 |
|---|---|---|
| A | 日付 | 入力日（自動） |
| B | 商品名 | 内部キー（英語表示→日本語で保存） |
| C | 現在在庫数 | **スタッフが入力する唯一の数値** |
| D | 入力者 | スタッフ名 |
| E | 記録時刻 | 自動 |

> 同じ日・同じ商品を再入力すると上書きされます（1日1レコード）。

---

## ④ 分析（全自動計算・閲覧専用）

商品名／単位／累計入荷数／現在在庫／累計販売数／当日販売数／販売率／残在庫率／
入荷からの日数／1日平均販売数／在庫日数／完売予測日／在庫金額JPY／想定売上JPY／
想定粗利JPY／発注ステータス

---

## ⑤ 発注判断（自動・色分け）

緊急度／商品名／現在在庫／単位／在庫日数／1日平均販売数／完売予測日／発注推奨
- 🆘完売・🔴至急 → 赤背景
- 🟡準備 → 黄背景
- 🟢十分 → 非表示

---

## ⑥ ダッシュボード（自動）

- 経営サマリー：在庫金額・想定売上・想定粗利（合計）
- 🔥 売れ筋ランキング（累計販売数 上位）
- ♻ 回転率ランキング（販売率 上位）
- 🐌 売れ残り注意（販売率 下位）

---

## ⑦ 設定

| セル | 項目 |
|---|---|
| B2 | 為替モード（自動／手動） |
| B3 | 自動レート（GOOGLEFINANCE） |
| B4 | 手動レート |
| B5 | 採用レート（=自動 or 手動） |
| B6 | 在庫日数 赤閾値（既定3） |
| B7 | 在庫日数 黄閾値（既定7） |

---

## 計算ロジック（中核）

```
累計入荷数   = Σ(入荷管理.入荷数)
現在在庫     = 日次在庫の最新値
累計販売数   = 累計入荷数 − 現在在庫
当日販売数   = 前日在庫 + 当日入荷 − 当日在庫
販売率       = 累計販売数 / 累計入荷数
残在庫率     = 現在在庫 / 累計入荷数
入荷からの日数 = 今日 − 初回入荷日（最小1）
1日平均販売数 = 累計販売数 / 入荷からの日数
在庫日数     = 現在在庫 / 1日平均販売数
完売予測日   = 今日 + 在庫日数
在庫金額     = 現在在庫 × 実質原価JPY
想定売上     = 現在在庫 × 売価JPY換算
想定粗利     = 現在在庫 × 粗利JPY

発注ステータス:
  現在在庫 = 0                          → 🆘 完売・発注推奨
  在庫日数 ≤ 3 または 在庫 ≤ アラート基準  → 🔴 至急発注
  在庫日数 ≤ 7                          → 🟡 発注準備
  それ以外                              → 🟢 十分
```
