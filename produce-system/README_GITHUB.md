# このフォルダについて

Midori No Mart の青果（野菜・果物）在庫・販売分析システムです。
Google Apps Script + Google スプレッドシートで動いています。

- `src/Code.gs` — スプレッドシート側の処理本体
- `src/WebApp.gs` — スタッフ入力用ウェブアプリの処理
- `src/StaffInput.html` — スタッフ入力画面
- `docs/` — シート設計、運用マニュアル、スタッフ向けガイド（英語・タガログ語）

## 注意

スタッフ用ウェブアプリのURLは、このリポジトリが公開設定のため
`<STAFF_APP_URL>` に置き換えています。実際のURLは
`C:\Users\smaed\midori-produce-system\docs\` 内の元ファイルにあります。

このフォルダは記録用のコピーです。動いているコードは
Google Apps Script 側にあるため、変更したら手動でここも更新してください。
